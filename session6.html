1. التدريب على الويب (Teachable Machine) 1. Web Model Training

نلتقط 30 صورة للغرض الأول و 30 صورة للغرض الثاني، والضغط على Train ليقوم الموقع بإنشاء النموذج في ثوانٍ! We snap 30 images of Object A and 30 of Object B, click Train, and get an AI model in seconds!

2. نقل النموذج لكود Python 2. Exporting Model to Python

نقوم بتحميل ملف `keras_model.h5` وملف `labels.txt` وقراءتهما داخل بايثون لاستخدامه محلياً بدون إنترنت. We download `keras_model.h5` and `labels.txt` and load them into Python to run offline.

3. نسبة الثقة (Confidence Percentage) 3. Confidence Score Threshold

النموذج يعطينا نسبة مئوية (مثلاً: 97% موبايل)، ونحن نضع شرطاً في الكود: إذا تجاوزت 90% ننفذ الإجراء! The model outputs a probability percentage (e.g. 97% Phone). We execute actions if confidence > 90%!
