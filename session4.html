1. الصوت الرقمي (Digital Audio) 1. Digital Audio

الصوت هو اهتزازات في الهواء. الميكروفون يحولها إلى موجات كهربائية، والـ AI يحول تلك الموجات إلى كلمات نصية! Sound is vibration in the air. Microphones convert vibrations to electrical signals, and AI converts signals into text!

2. التحدث الآلي (Text To Speech - TTS) 2. Text-To-Speech (TTS)

تقنية تحول أي نص مكتوب إلى صوت متكلم بنبرات مختلفة وسرعات محددة. Technology converting any written text into spoken voice with customizable pitch and speech rate.

3. الأوامر الذكية الاستجابية 3. Smart Voice Commands

عند قراءة كلمة أمر مثل 'افتح يوتيوب'، يستخدم الكود مكتبة `webbrowser` لتنفيذ الأمر فورياً! When detecting command phrases like 'open YouTube', Python executes the command instantly via `webbrowser`!

import pyttsx3 import datetime import webbrowser engine = pyttsx3.init() def speak(text): print(f"🎙️ المساعد: {text}") engine.say(text) engine.runAndWait() speak("أهلاً بك يا مهندس المستقبل! أنا مساعدك الصوتي الذكي.") command = input("أدخل أمرك الصوتي النصي (الوقت / يوتيوب): ") if "وقت" in command: now = datetime.datetime.now().strftime("%H:%M") speak(f"الساعة الآن هي {now}") elif "يوتيوب" in command: speak("جاري فتح يوتيوب لك الآن!") webbrowser.open("https://youtube.com")
