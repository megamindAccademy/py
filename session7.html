1. قراءة إيماءات اليد (Gesture Recognition)

النموذج يتعرف على قبضتك (حجر)، كفك المفتوح (ورقة)، أو أصبعيك (مقص) في التو واللحظة.

2. عشوائية الكمبيوتر ومنطق الفوز

الكمبيوتر يختار حركة حرة باستخدام `random.choice` ثم يقارن حركته بحركة يدك أمام الكاميرا ويحدد الفائز صريحاً.

3. لوحة النتيجة الرقمية (Live Score Board)

إظهار النتيجة مباشرة فوق شاشة الكاميرا باستخدام أمر `cv2.putText` لتجربة ممتعة للغاية!

التجربة العملية التفاعلية المباشرة 🧪

محاكي لعبة حجر ورقة مقص ضد الـ AI (RPS Interactive Sim)

اختر حركتك وشاهد اختيار الذكاء الاصطناعي ومن سيكسب الجولة!

✨ في انتظار مدخلاتك واختبار النظام الذكي...

تطبيق الكود بـ Python 🐍

rps_ai_game.py Python 3.x
import random choices = ["حجر ✊", "ورقة ✋", "مقص ✌️"] def play_round(user_choice): ai_choice = random.choice(choices) print(f"أنت اخترت: {user_choice} | الـ AI اختار: {ai_choice}") if user_choice == ai_choice: return "تعادل! 🤝" # منطق الفوز return "مبروك! لقد هزمت الذكاء الاصطناعي! 🎉" print(play_round("حجر ✊"))
